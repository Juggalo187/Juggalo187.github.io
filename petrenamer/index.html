How to Use in Anarchy Online

  1. Generate your macro using this tool
  2. Copy the macro command to clipboard
  3. In AO, paste the command into a chat window
  4. Press Enter to execute
  5. Drag Macro button to Hotbar

Important Limits:

  • Single color: Maximum 29 characters
  • Rainbow names: Maximum 10 letters
  • Multi-color: total macro must be under 59 characters
  • No spaces: AO color codes break with spaces
